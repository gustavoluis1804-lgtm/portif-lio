# Portfólio Gustavo Luis — Vercel

Este projeto é um site estático completo. O arquivo index.html fica na raiz; a pasta assets contém imagens, vídeos e scripts.

## Publicar pela Vercel

1. Extraia este ZIP e envie o conteúdo extraído para um repositório no GitHub. O index.html precisa ficar na raiz do repositório.
2. Na Vercel, escolha Add New > Project e importe esse repositório.
3. Em Framework Preset, escolha Other. Deixe Root Directory como . (raiz) e Output Directory vazio; não é necessário comando de build.
4. Clique em Deploy.

Links dos projetos externos abrem nos respectivos sites publicados. O formulário de contato não depende de servidor: os canais abrem e-mail, telefone, GitHub e LinkedIn.
